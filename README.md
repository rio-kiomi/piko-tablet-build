# Piko 安卓平板右侧信息流定制版

基于 https://github.com/NihilDigit/piko 的 v1.2.0，固定源码提交为
`1a3e7916e2a8f43f11e829e2911547e2790b1205`。

## 改动

- Android 横屏且窗口高度至少 480dp、内容区至少 840dp 时，信息流显示在文件列表右侧。
- 竖屏、折叠或分屏导致空间不足时使用全屏信息流。
- 保留安卓触屏按钮、导航和添加链接面板；桌面端布局不变。
- 信息流里手动开启的横屏播放保持全屏，退出该模式后再自动判断分栏。
- 平板分栏刷信息流时打开其他任务，仍按移动端规则确认结束信息流。

## 云端构建

此目录只包含构建工作流和补丁，不要求本机安装开发环境。
在独立 GitHub 仓库中保存这些文件后，手动运行 Actions 中的 `Build Piko tablet APK`。
工作流读取固定上游源码、应用补丁、执行单元测试、编译桌面端和安卓端，最后校验 APK 签名及包名。
APK、完整修改版源码、许可证、SHA256 校验和及测试报告作为 Actions artifacts 保存 30 天，不创建 Release。

本地可审核的改动为 `tablet-feed.patch`。没有增加项目依赖。

## 安装说明

输出 `piko-1.2.0-tablet.1-arm64-v8a.apk`，名称为 `Piko 平板`。
这是使用项目 debug 变体签名的个人测试包，包名 `dev.piko.debug`，可与官方 `dev.piko` 并存；首次打开需要重新登录。
云端临时生成的 debug 签名不保证在不同构建间一致；后续长期维护版本应使用固定的自有签名密钥。
不要用官方自动更新覆盖此定制版。桌面端不会输出安装包。

首次使用需在实际平板上确认：右侧上下刷视频、左侧文件操作、关闭信息流、看完整后返回、在网盘中显示后继续刷，
以及横竖屏、折叠和分屏切换。云端单元测试和签名校验不替代真实设备上的播放验证。
